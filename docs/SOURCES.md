# Data sources — MapleStory Classic World (survey P3-T0)

**Survey date:** 2026-10-05 (the day before Founder's Access). **Re-run:** monthly while the game is new, and after every major patch.

## Purpose

Every game fact the app shows must carry a source and a confidence label (MASTER_PLAN §6). This file lists the sources we found that cover MapleStory **Classic World** and says how the app may use each one. Sources that publish pre-Big-Bang GMS/MapleSEA numbers, modern GMS numbers or private-server numbers are listed only so nobody adds them by mistake.

## Tiers (from MASTER_PLAN §6.1)

| Tier | Meaning |
|---|---|
| **A — Official** | Nexon news, FAQ and release notes (read through the public CMS JSON `g.nexonstatic.com/maplestory/cms/v1`). |
| **B — In-game / field notes** | What the owner sees in the live game (screenshots preferred). Main source for monsters, maps, spawns, drops and quests. |
| **C1 — NiaMeowDB** | Link-only. No tool or AI agent crawls, scrapes or bulk-copies it. |
| **C2 — Other community** | Wikis, databases, guides and videos about Classic World. Usable only if listed below as `approved`. |
| **X — Legacy** | Pre-Big-Bang GMS/MapleSEA, modern GMS, private servers, old guides. Never shown as a Classic World fact. |

## Status rules

- `approved`: licence allows reuse with attribution **and** the numbers are Classic World. Data may be entered by hand into the datapack with a citation.
- `link-only`: useful, but terms or robots.txt forbid reuse or automated access (or grant no licence). The app may only deep-link; nobody copies its data.
- `rejected`: legacy, private-server, modern-GMS, unreliable or no Classic World data.

**Only two statuses are decided: Nexon official = `approved`, NiaMeowDB = `link-only`. Every other status below is PROPOSED and awaits the owner's approval.**

All fan data seen today is **pre-launch** (Closed Online Test 2 in Aug 2026, or the pre-download client). Fan sites do not agree on every number (see Notes). Treat any value from them as `likely` at best until checked in the live game.

How this survey was done: only terms pages, robots.txt files and 1 to 3 sample pages per site were read. Sites whose robots.txt blocks AI agents were not opened beyond that. meowdb.com was not visited. "Unverified" means we could not confirm it directly (blocked fetch, login wall, or search-engine snippet only).

## Gaps (no usable approved source — must come from the owner's in-game field notes, §6.5)

If the owner approves MapleClassic Wiki, it can supply *pre-launch* (`likely`) values for monsters, maps, spawn maps, NPCs, quests, skills and a training-spot guide. Every value still needs in-game confirmation. If it is not approved, **all** of the items below come from field notes only.

1. **Drop rates.** Nexon publishes none. MapleClassic Wiki shows "–". Only field notes or logged kills (`sampled`) can fill this.
2. **Character EXP table** (EXP to next level, Lv 1–100). No Classic World source found. MapleClassic Wiki has only a crafting EXP table, and its claim that monster EXP depends on level alone is unverified.
3. **Formulas:** level-difference EXP penalty, accuracy/miss, damage. No source.
4. **Launch-version monster stats.** All fan data is pre-launch and sources disagree (Blue Mushroom HP 342 vs 346; Mushmom HP 34,440 vs 36,660). Confirm in the live game from 6 Oct 2026.
5. **Spawn counts, respawn timing, map crowding, EXP/hour.** No source.
6. **Quest steps and rewards as shipped**, and **NPC locations** beyond those Nexon names (job advancement, crafting, citizenship, event NPCs).
7. **Content scope at launch:** whether Ossyria and 3rd job are available (MapleClassic Wiki's training guide includes Orbis/El Nath monsters, so it may not match launch content).
8. **Sprites and images.** All Nexon property; no approved source (P9 sprite spike).
9. **Training-spot recommendations** that are quantitative. Fan guides and videos are opinion; use them as links, not data.
